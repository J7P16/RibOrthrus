BAM FILE NOTES
===============



Goal:
-----
Fully understand BAM files and their encodings and how to analyze them



Plain Definition:
-----------------
BAM file is a compressed binary table of sequencing reads aligned to a
reference genome.

It answers questions like: "This short DNA/RNA sequencing read came from
chromosome 1, around position 123456, aligned with this quality, with these
mismatches/insertions/deletions.

Official format is SAM/BAM. SAM is the readable text version; BAM is the 
compressed binary equivalent. Each non-header SAM/BAM alignment record has core
fields like read name, chromosome, position, mapping quality, CIGAR, string,
mate information,



Basic/Foundational Understanding:
---------------------------------
DNA/RNA sequencing machines produce short strings such as:

ACTGACTGACTG...

These are called reads. A reference genome is a long known sequence, like:

chr1: ACTGACTGACTGACTG...
chr2: GGGCTAT...
...

An aligner tries to place each read onto the reference genome. The BAM stores
those results. So a BAM file is not usually the entire genome itself. It is 
just many reads mapped onto a genome/transcriptome. 



Fields I Must Know Within BAM/SAM files:
----------------------------------------
A typical SAM line looks like this:

read123  99  chr1  10045  60  76M  =  10120  151  ACTG...  FFFF...

   FIELD       MEANING
   -----       -------
1. QNAME       read name
2. FLAG        bit flags describing read status
3. RNAME       chromosome/reference name
4. POS         1-based alignment start
5. MAPQ        mapping quality
6. CIGAR       alignment structure
7. RNEXT,      mate read location
   PNEXT
8. SEQ         read sequence
9. QUAL        base quality string



Understanding the FLAG field:
-----------------------------
FLAG is an integer encoding many yes/no properties. For example:

read is paired?
read is unmapped?
mate is unmapped?
read is reverse complemented?
read is duplicate?
read failed QC?
etc.

Thankfully, in Python libraries, you usually do not manually decode the integer.
You use attributes like:

read.is_paired
read.is_unmapped
read.is_reverse
read.is_duplicate
read.is_secondary
read.is_supplementary

samtools flagstat summarizes these categories from a BAM file.



Understanding the MAPQ field:
-----------------------------
MAPQ means mapping quality. Roughly, it means "How confident is the aligner that
this read is placed in the correct location?

Common filtering:
MAPQ >= 20
MAPQ >= 30

Higher means more confident. But exact interpretation can depend on the aligner,
so do not treat it as perfectly universal.



Understanding the CIGAR field:
------------------------------
The CIGAR string describes how the read aligns to the reference.

Common operations:

Symbol      Meaning 
------      -------
M           aligned match or mismatch
=           exact match
X           mismatch
I           insertion relative to reference
D           deletion relative to reference
S           soft clipping
H           hard clipping
N           skipped region, common in RNA-seq splicing

Examples:
76M     means 76 bases aligned.
50M2I24M    means 50 aligned bases, 2 inserted bases, then 24 aligned bases.
10S66M      means 10 soft-clipped bases, then 66 aligned bases.

For RNA-seq, you may see:
40M1000N36M
That often means the read spans an exon-exon junction.



Common/Necessary Installation Tools for BAM Files:
--------------------------------------------------

Samtools is the standard suite for viewing, sorting, indexing, filtering,
and summarizing SAM/BAM/CRAM files.

For the command line, install samtools by using:
conda install -c bioconda samtools

Pysam is a Python wrapper around htslib/samtools functionality and is commonly
used to read and manipulate SAM/BAM files in Python.

For Python, install pysam by using:
pip install pysam
